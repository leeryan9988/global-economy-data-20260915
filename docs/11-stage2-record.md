# 阶段 2：World Bank 数据接入与同步

验证完成时间：2026-09-16 01:31（北京时间）。

## 范围与实现

本阶段实现 World Bank API v2 数据客户端、六指标顺序同步、指标级事务、同步日志、并发互斥、幂等插入和历史值修订提案。运行脚本读取 `DATABASE_URL`，默认请求 1960 年至当前年份。

客户端固定使用 WDI `source=2`，一次请求 8 国，遍历全部分页。它会校验页码、总数、来源更新时间、国家、指标、年份、重复键与数值格式；保留 null、0 和负值。429、5xx 与临时网络故障最多尝试 3 次，并支持 `Retry-After`。

同步先完整获取并校验一个指标，再开启数据库事务。新键只插入一次，相同值保持不变；来源历史值改变时生成去重的待审核提案，核心数据不被自动覆盖。单项失败会记录错误并保留其他指标和既有可读数据。

## 真实数据结果

- 数据源：World Bank API v2，source 2。
- 来源标记更新时间：六项指标均为 2026-07-13。
- 请求范围：1960—2026；接口实际返回 1960—2025 共 66 个年度位置。
- 覆盖矩阵：48/48 个国家与指标组合有返回。
- 一次性 PostgreSQL 导入：3,168 条年度记录，包含来源明确返回的 null。
- GDP、人均 GDP、人口的 8 国数据均为 1960—2025 非空。
- 失业率的 8 国有效期均从 1991 年开始。
- 贷款利率历史缺口明显：德国、法国在该指标下返回了年度位置，但 66 年全部为 null；不会用政策利率或其他利率替代。

详细覆盖表见 `reports/world-bank-coverage-2026-09-16.md`，机器可读结果见同名 JSON。

## 环境排查

Windows 隔离账户不能调用 PostgreSQL 的 restricted-token 初始化流程。验证程序复制上一阶段已验证且正常关闭的空测试集群，再直接启动复制件；旧测试集群未被修改。测试结束后 PostgreSQL 正常快速关闭，全部临时文件保留，没有删除或覆盖既有内容。

隔离账户还可能令 `tsx` 读取 Windows 用户资料时报错。验证运行器在进程内为这项系统调用提供仅用于临时目录命名的后备用户名，不改变应用代码、系统账户或用户环境设置。
