# 阶段 3：首页

验证完成时间：2026-09-16 02:03（北京时间）。

## 范围与实现

将公开首页从“网站筹备中”升级为真实经济数据概览。首页包含导航、项目介绍、数据范围、8 国数据卡、同年 GDP 排名和数据口径说明。

每个国家卡片展示 GDP、人均 GDP、人口、通胀率、失业率和贷款利率。每项数值旁单独显示实际年份；页面格式化用于阅读，版本化快照仍保留 World Bank 原始十进制字符串。GDP 排名选择 8 国都有有效值的最近共同年份，不混用年份。

页面采用构建时静态快照，因此用户访问不依赖 World Bank 实时响应；上游短时故障不会让已发布首页失去已有数据。快照由脚本从 World Bank API v2 重新生成，使用新文件写入保护，防止无意覆盖既有快照。

## 当前页面数据

- 数据源：World Bank WDI，source 2。
- 来源数据更新时间：2026-07-13。
- 首页快照生成时间：2026-09-16 01:52（北京时间）。
- GDP 排名年份：2025，8 国均有有效值。
- 德国、法国贷款利率明确显示“暂无数据”；其他国家的贷款利率按各自最近有效年份展示。
- 页面明确说明 GDP 为现价美元，贷款利率不是央行政策利率。
