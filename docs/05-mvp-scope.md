# MVP 边界

## 必须包含

- 仅中国、美国、日本、德国、印度、英国、法国、韩国。
- 仅 GDP、人均 GDP、人口、通胀率、失业率、贷款利率。
- 年度历史数据、首页、国家列表/详情、指标详情、对比、排名、数据说明。
- 2–5 国比较，年份与区间选择，图表和表格，来源与更新信息，手机适配。
- PostgreSQL 缓存、幂等同步、日志、缺失处理、来源修订保护。

## 不进入 MVP

登录、评论、会员、AI 分析、新闻、股票行情、汇率、债券、商品、PMI、贸易、政府债务、200+ 国家、央行政策利率。不额外制作管理后台；同步和批准修订使用受控操作流程。深色模式可选但不影响首版完成。

## 数据质量边界

“8×6”表示支持 48 组查询，不等于每组每年都有值。来源缺失可通过明确说明满足验收；伪造、补零、使用另一指标冒充不通过验收。贷款利率仍保留，即使个别国家整个区间缺失。

## 技术与部署边界

框架和组件使用用户指定技术栈，具体稳定版本在阶段 1 查证并锁定。GitHub 负责代码管理，Vercel 负责本项目应用发布，Supabase 提供 PostgreSQL。独立新仓库和新部署项目，不修改旧项目。

GitHub Pages 通用规则与本次 Vercel 指定存在差异，本规范采用最新具体要求 Vercel。阶段 8 先完成构建、环境变量清单和部署验证准备，不在早期创建云端资源或声称上线完成。
