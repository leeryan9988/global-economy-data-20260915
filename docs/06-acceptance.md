# 阶段计划与验收标准

每阶段完成：记录新增文件、行为变化、验证方法、实际结果、未验证项、问题与下一步；通过后才推进下一阶段。不得把“文件存在”记成“功能正常”。

| 阶段 | 交付 | 验证与完成门槛 |
|---|---|---|
| 0 文档与选型 | 本规范、候选比较 | 六类规范齐全；用户确认复用/新建路线 |
| 1 项目结构与 schema | Next.js 基础壳、目录、类型、种子、SQL 迁移、环境变量样例 | 类型检查、lint、生产构建；隔离 PostgreSQL 迁移成功，8 国/6 指标，唯一键/外键/RLS 生效 |
| 2 数据接入与同步 | World Bank 适配、事务同步、日志、覆盖报告 | 48 组真实覆盖报告；中国 GDP 样本对照；分页、null、0、负数、429、失败回滚、重复和并发同步测试；变更值不自动覆盖 |
| 3 首页 | 概览、排名摘要、数据说明基础版 | 真实数据库值与来源一致；每项年份准确；加载、无数据、上游故障后已有数据可用；桌面/手机检查 |
| 4 国家详情 | 8 国列表与详情、六项历史表 | 所有 slug 可访问，非法 slug 404；贷款利率也有位置；每个指标年份独立；缺失不报错 |
| 5 图表 | ECharts 封装、首页/国家趋势、指标页 | 5/10/20/全部窗口准确；tooltip 年份单位数值匹配；null 断线、单点与全空合理；resize/触摸/销毁检查 |
| 6 对比页 | 2–5 国选择、指标、区间、分享 URL | 1 或 6 国被拒；2 与 5 国可用；参数刷新恢复；统一年份轴；所有六指标可切换 |
| 7 排行榜 | 同年六指标排名、覆盖与缺失信息 | 不混年；零/负数可排序；空值不排名；并列使用竞赛排名 1,1,3；相同值按 ISO2 稳定展示 |
| 8 部署准备 | 独立仓库方案、Vercel 配置、Supabase 环境说明、受保护调度、运维说明 | 生产构建、密钥不在客户端、数据库权限、预览环境 smoke test、链接/SEO/手机检查；记录未就绪账号或凭据 |

## 关键数据验收案例

- 最新一年 null，上一年为 0：最新有效值应为上一年的 0。
- 指定 2024 年缺失而 2023 年有值：显示 2024 暂无数据，不替换。
- 对比序列 [1, null, 3]：中间保留缺口。
- 8 国无共同有效年份：明确默认选用年份和覆盖 n/8，缺失项不参与排名。
- 相同同步重复执行：核心数据行数不增加，日志可新增。
- 来源修订旧值：生成去重提案，旧值仍可读；未经明确同意不改写。
- 上游失败：数据库已有值仍可读；不更新最近成功同步时间。

## 性能与界面目标

原方案“首页尽量 <2 秒、API 尽量 <500ms”保留为目标：部署预览环境记录设备、网络、区域与缓存状态；首页测 LCP，API 至少 20 次记录 p50/p95，分别报告冷/热请求。首页 LCP 目标 2 秒以内，热缓存只读 API p95 目标 500ms 以内；未达标记录瓶颈，禁止无实测声称通过。

视口至少 375px 和 1440px。页面无整体横向溢出；表格可局部滚动。键盘可访问选择器与导航；图表配数据表；错误和加载状态清晰。指标页和国家页有独立标题、描述与规范 URL。

## 阶段记录格式

记录标题包含日期与北京时间。内容依次为：范围、文件、验证证据、结果、未验证项、问题与原因、后续动作。仅新增记录或新版本，覆盖旧记录需要先确认。
